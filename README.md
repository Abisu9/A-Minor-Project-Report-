# A Minor Project Report

## Drinking Water Quality Checker

### Project Overview

This repository contains a comprehensive minor project report on **Drinking Water Quality Checker** - a web-based application designed to monitor and assess the quality of drinking water based on various physical and chemical parameters.

### About the Project

The Drinking Water Quality Checker is an automated system that helps assess water quality by analyzing multiple parameters including pH level, Total Dissolved Solids (TDS), turbidity, hardness, and chlorine content. The system compares these measurements against WHO and EPA standards to provide instant feedback on water safety.

### Key Features

- **Real-time Water Quality Assessment**: Instant analysis of water parameters
- **User-Friendly Interface**: Accessible to both technical and non-technical users
- **Historical Data Tracking**: Store and analyze water quality trends over time
- **Report Generation**: Create detailed PDF reports of water quality assessments
- **Data Visualization**: Interactive charts and graphs for trend analysis
- **Educational Content**: Information about water quality parameters and health implications
- **Standards Compliance**: Comparison with WHO and EPA guidelines

### Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap, Chart.js
- **Backend**: Python (Flask/Django)
- **Database**: SQLite/MySQL/PostgreSQL
- **Libraries**: Pandas, NumPy, ReportLab

### Water Quality Parameters

The system evaluates the following parameters:

1. **pH Level** (6.5-8.5 safe range)
2. **TDS - Total Dissolved Solids** (<500 ppm excellent)
3. **Turbidity** (<5 NTU safe)
4. **Hardness** (categorized as soft, moderate, hard)
5. **Chlorine** (0.2-4.0 ppm safe range)
